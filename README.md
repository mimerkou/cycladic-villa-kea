# Cycladic Villa Kea

Homepage of Cycladic Villa Kea, a private villa above Ioulida on Kea, Greece.

Static site (HTML, CSS, JS), no build step. Open `index.html` or deploy the repository root to any static host (Netlify, GitHub Pages).

- `index.html` — homepage (English by default, Greek via the EN/EL switcher)
- `css/style.css` — styles
- `js/main.js` — scroll scenes, language switcher, menu, video clips
- `assets/img`, `assets/video` — photos and video clips

Version: v4.8
